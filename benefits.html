Work Environment

働く環境

一人ひとりが安心して挑戦を続けられるよう、制度と働く環境を常にアップデートしています。

Flexibility & Work Style

働き方の柔軟性

フルフレックス制度（コアタイム無し）

コアタイム無しのフルフレックス制度。1日1時間以上勤務で出勤扱いとなり、時間の使い方を自由に設計できます。

Icon

時短勤務制度

育児・介護など、ライフステージの変化に合わせて短時間勤務が選べる制度。実際に利用しているメンバーも。

Icon

入社初日から有給付与

入社初日から有給休暇を付与。入社直後の急な用事や体調不良にも、柔軟に対応できる制度です。

Icon
Growth & Development

育成・成長支援

学習支援制度（書籍購入・資格取得・講座受講の全額会社負担）

業務に関わる書籍・雑誌は全額会社負担。加えて資格取得や外部講座など、学びに関わる費用を会社が支援します。

Icon

外部勉強会補助

業界の勉強会・カンファレンスなど、外部での学びを補助。社外の知見を業務に活かせる環境を整えています。

Icon

クロスメンター制度

入社後、事業部メンターとは別に他事業部のメンターがつく制度。部門を超えたつながりで、キャリアの視野を広げます。

Icon
Life Events & Family Support

ライフイベント・家族支援

育休・産休制度（産後パパ育休あり）

産休・育休はもちろん、産後パパ育休制度も整備。男女問わず、育児と仕事の両立を支援します。

Icon

ベビーシッター割引制度

ベビーシッターサービスを割引価格で利用できる、育児中のメンバー向けの支援制度です。

Icon

慶弔見舞金・出産祝い金

結婚、出産、家族の慶弔などのライフイベントに、会社からのお祝い金・お見舞金を支給しています。

Icon
Compensation & Evaluation

待遇・評価

カンパニーボーナス（業績連動賞与）

会社全体の業績に応じたボーナスを支給。事業の成果が、メンバーの成果としてしっかりと還元されます。

Icon

表彰制度

優秀なメンバーやチームの挑戦と成果を、社内で称える表彰制度です。頑張りに光を当てる文化を大切にしています。

Icon

副業可

社員の3割以上が実際に副業を行っています。社外での経験や学びを、Urumoの業務にも還元できる環境です。

Icon
Communication & Culture

コミュニケーション促進

オフサイト・全社会議

オフサイトや全社会議など、部署を越えた交流の機会を用意。

Icon

Beerbash

3ヶ月に一度、オフィスでライトなパーティを開催。仕事の枠を越えたメンバー同士の交流を大切にしています。

Icon

部活動制度（16の部活）

フットサル、キャンプ、日本酒、麻雀など、16の部活動が活動中です。仕事を離れた仲間との時間も大切にしています。

Icon
